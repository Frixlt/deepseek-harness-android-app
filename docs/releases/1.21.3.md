# DeepSeek Harness 1.21.3 — оверлей и Live2D

- Чиби и полноразмерная модель используют исходный стоячий риг. Удалена неудачная деформация сидячей позы; ноги и юбка больше не растягиваются процедурно.
- Размер персонажа: 40–360 dp с ограничением по экрану. Исправлены прозрачные поля, обрезание шапки и прижатие полноразмерной модели к краю экрана. Сохранённый размер сохраняется после обновления.
- Добавлены четыре уровня качества: экономия, стандартное, высокая чёткость и максимальное сглаживание. Высокое качество учитывает реальную плотность экрана; максимальная сторона буфера — 2048 px.
- Нажатия учитывают прозрачный силуэт модели: пустоты вокруг неё и между частями тела пропускают касания. Панель управления больше не появляется от нажатий в прозрачную область.
- Добавлены 18 состояний ассистента и предпросмотр эмоций. Размышление показывает анимированный индикатор исходного рига. Исправлены потеря последнего события, устаревшие статусы и сброс эмоции при закрытии подписи.
- Исправлено вмещение надписей в кнопках плавающей панели; длинные подписи переносятся.
- Плеер включён в APK, создаётся по необходимости и при скрытии останавливает собственную анимацию. Добавлены проверки событий, качества, геометрии и прозрачных областей.

## Установка

Установите `DeepSeekHarness-community.apk` поверх прежней community-версии с той же подписью. Удалять приложение и очищать данные не требуется. Это обычная сборка без режима отладки.

Live2D-модели и лицензированные библиотеки хранятся отдельно и в APK не включены. Ранее установленный локальный пакет продолжает использоваться. Новая сидячая поза не заявляется; обе модели пока стоят.

Для предкомпиляции установленной версии на своём устройстве:

```sh
adb shell cmd package compile -m speed -f com.deepseek.harness.community
```

Предкомпиляция ART выполняется на конкретном устройстве после установки, а не переносится с APK. На подключённом телефоне проверена установка поверх прежней версии с сохранением данных и режим ART `speed`.

Подробности и команды проверки: [docs/AVATAR.md](https://github.com/Frixlt/deepseek-harness-android-app/blob/v1.21.3-community/docs/AVATAR.md).
